# ADR 0010 – Aucun port entrant ouvert par défaut

- Statut : Accepté
- Date : 2026-11-19
- Décideur : responsable du projet (validation de l'étude d'architecture, Phase 1)

## Décision

Aucun composant n'écoute sur le réseau dans la configuration par défaut.

## Conséquences

Webhooks entrants et API distante uniquement après activation explicite par un administrateur, auditée et documentée.
