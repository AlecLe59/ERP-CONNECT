# @erp-connect/contracts

Types et constantes du protocole JSON-RPC interface ↔ moteur, **générés** depuis `src/ErpConnect.Contracts`.

- `src/generated.ts` : ne jamais modifier à la main. Régénérer avec
  `dotnet run --project tools/ErpConnect.Tools.ContractGen` depuis la racine du dépôt.
- Le test `ErpConnect.Contracts.Tests` échoue si ce fichier n'est pas à jour.
